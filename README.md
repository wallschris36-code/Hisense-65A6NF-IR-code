This was created testing known RC5 and NECext IR codes to find a set that worked for all commands on this particular TV.
May work for other Hisense/Fire TV branded models. Untested/uncomfirmed.
The need was made apparent by existing remote profiles in the Flipper Zero Remotes Library not working fully for this model.
This can be used with Flipperzero via the infrared application. 
Simply copy it to the Infrared folder and open it as saved remotes.
I also generated an un tested .irui file for use in the Flipper mobile app remotes library but haven't the time or know how to get it added to it.
